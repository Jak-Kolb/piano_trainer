# Keys

Local piano practice trainer (see `piano_trainer_spec.md`).

## Run

```bash
npm install
npm start
```

Opens a production preview at `http://127.0.0.1:5173/` — use **Chrome**.

Dev mode: `npm run dev`

One-click (macOS): copy `scripts/Keys.command` to your Desktop and double-click (after `npm install`).

## Stage 1 (this branch)

- Vite + React + TypeScript + Tailwind design tokens
- Theory core with triad spelling tests
- Self-report input + triad recall drill

## Test

npm test
